# Fonu v2.0.0

Fonu 2.0 正式版：以 Nginx 反向代理为核心，支持 FRP 内网穿透，面向飞牛 fnOS 与 Docker 部署。

## 主要更新

- 全新响应式 V2 界面，支持深浅色主题及经典品牌配色，适配飞牛窗口化和全屏使用。
- 反向代理：独立规则、多域名、多端口、业务分组、卡片/列表、服务发现、访问控制、流量统计、Nginx 配置校验及回滚。
- 上游运行诊断：实际连接地址、HTTP 协议、DNS、TCP、TLS、首字节耗时及上游证书到期时间。
- DDNS：多域名任务、DNSHE 账户、独立 IPv4/IPv6 探测与自动同步。
- 证书：ACME 申请、导入、自动续签、DNS 凭证关联、本地与 SSH/SFTP 部署及部署历史。
- FRP：内置 frpc 0.72.0，支持 Web 网关、TCP/UDP 隧道、连接诊断与日志（需自备 frps 服务端）。
- 仪表盘：访问与安全分析、进程版本、CPU、内存、Nginx 运行状态；优化长时间范围统计查询。
- 通知：邮件、Webhook、Telegram、企业微信、飞书，支持 DDNS、证书、异常访问、安全事件及 Nginx 重载失败提醒和发送记录。
- 备份恢复：支持导出、上传恢复、本地备份创建、下载、恢复、删除及自动备份保留策略。
- 安全与稳定性：旧固定密钥自动随机化迁移、凭证重新加密、备份校验、限流、日志采集事务、分批清理及资源回收。

## 安装与升级

从 Assets 下载与设备架构相匹配的 FPK，日常使用推荐普通权限包，确需特权访问时选择 root 包。Docker 支持 amd64 和 arm64，镜像 `muxui/fonu:2.0.0` 或 `muxui/fonu:latest`。

升级前完整备份数据目录、数据库、证书、配置及原有密钥。保留原数据覆盖升级，升级后可能需要重新登录。旧固定密钥由后台自动迁移；自定义密钥继续保留。不要直接使用升级后的数据库降级至 v1。

使用 `SHA256SUMS.txt` 校验安装包。详细部署与使用说明见 [README](https://github.com/O96u/Fonu/blob/v2/README.md)。
