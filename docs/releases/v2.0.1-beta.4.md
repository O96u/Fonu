# Fonu v2.0.1-beta.4

第四个测试预发行版，继承 beta.3 的修复。正式版 v2.0.0 与 Docker latest 保持不变。本次仅发布飞牛 FPK 测试包。

## SMTP 邮件兼容性
- 中文及 Emoji 邮件主题使用 RFC 2047 UTF-8 Base64 编码，长编码主题按 encoded-word 边界折行。
- 邮件正文使用 quoted-printable 传输编码，清理邮件头控制字符，防止邮件头注入。
- 新增 MIME 解码与长主题回归测试；QQ 邮箱、Outlook 的实际显示仍需收信验证。

## 访问日志
- 黑名单按钮根据当前配置显示加入黑名单、规则已加入、全局已加入、网段已覆盖等状态。
- 加入或解除后同步更新相关记录；刷新及翻页批量读取当前配置，历史 HTTP 状态保持不变。
- 延续 beta.3 的规则优先、未匹配服务时全局黑名单确认机制，避免扩大封禁范围。

## 反向代理
- 首次使用默认 V2 服务视图，之后记忆用户选择（服务视图或端口分组）。
- 刷新、重新进入页面后恢复同一浏览器保存的选择；清除本地数据后恢复默认视图。
- 保留不同视图对应的新增操作和入口内新增规则。

## 测试重点
- QQ 邮箱、Outlook 收到的中文及 Emoji 主题和正文。
- 同一规则相同 IP 的多条访问记录在加入及解除后同步更新；全局状态、CIDR 覆盖、刷新和翻页。
- 两种反代视图切换及刷新后恢复。
- 覆盖升级后原有通知、证书、DDNS 及反代配置。

升级前请备份数据库、配置、证书及密钥。测试版建议先在非生产环境验证，使用 SHA256SUMS.txt 校验对应架构及权限的 FPK。不要直接降级使用升级后的数据库。
