# Fonu v2.0.0-rc.01

这是 Fonu 2.0 的首个候选发布版（RC），面向飞牛 fnOS 测试，不是正式稳定版。稳定版仍可通过 v1 分支和历史 Release 获取。

## 主要更新

- 全新 V2 界面：经典品牌配色、响应式仪表盘、DDNS、证书、反代、FRP、日志及系统设置。
- 仪表盘：概览、访问分析、安全分析独立；IPv4/IPv6 公网探测；Fonu/Nginx/FRP 版本、CPU、RSS、Nginx 发布状态及错误日志。长时间范围概览按需查询，保留原始数据和准确独立 IP 统计。
- DDNS：多域名任务、DNSHE 账户、独立 IPv4/IPv6 开关、更新失败及 IP 变更通知。
- HTTPS 证书：申请、导入、单证书续签、自动续签策略、DNS 凭证关联、本地/SFTP 部署、失败回滚和部署历史。
- 反向代理：独立规则、业务分组、卡片/列表切换、服务发现、访问控制、Nginx 配置发布校验及回滚、上游诊断。
- FRP：Web 网关与 TCP/UDP 隧道、连接设置、运行日志与诊断；进程管理、输出限制。
- 通知：邮件、Webhook、Telegram、企业微信、飞书及安全事件；修复手动任务触发缺口，新增发送记录。
- 安全与稳定性：旧固定密钥自动随机化迁移，凭证重新加密，备份恢复校验，限流、日志采集事务、分批清理、资源回收、依赖漏洞检查及真实 Nginx 测试。

## 安装与升级

- 从 Assets 下载对应架构的 FPK，默认推荐普通权限包；root 包仅适合确有特权目录/端口需求的用户。
- 升级前完整备份数据库、证书、配置目录以及原有密钥/环境变量；保留原安装数据并覆盖升级，不要卸载后清空数据。
- 升级可能要求重新登录。旧固定密钥在启动时自动迁移；自定义密钥继续保留。不要直接替换密钥，也不要直接用升级后的数据库降级回 v1。
- RC 阶段仍需真机验证各通知平台、证书续签、备份恢复与长时间运行。请反馈实际问题。
