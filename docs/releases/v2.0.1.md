# Fonu v2.0.1

本次为 v2.0 稳定性与使用体验修复版本，整合 beta.1 至 beta.4 的改进。

### 反向代理与界面

- 恢复端口分组（#43）：服务视图与端口分组在主页面直接切换，首次默认 V2 服务视图，记忆浏览器选择；不同视图显示对应新增按钮，保留组内新增规则。
- HTTPS 编辑器展示候选证书和到期日期，缺失时提示申请或导入；后端继续验证实际证书、私钥与域名。
- 统一主题配色，移除侧栏重复 GitHub 链接。

### DDNS 与 ACME

- 修复多级公共后缀解析和相对记录拼接，兼容旧任务；根据服务商实际 Zone 解析域名（#45）。
- DNSPod 区分账户列表错误与解析记录空列表，支持首次创建 A/AAAA/TXT，采用服务商默认 TTL。
- 阿里云 DNS-01 TXT TTL 调整为 600 秒，保留 #44 原作者贡献并补充请求级测试。

### 通知与安全

- 通知历史持久化至 SQLite，保留最近 1,000 条发送元数据；支持重启后查询、分页及状态筛选。旧版本内存记录无法自动恢复。
- 统一通知正文、状态及处理建议；SMTP 中文与 Emoji 主题采用 RFC 2047 编码，正文使用 quoted-printable，增加邮件头控制字符防护。
- 访问日志支持黑名单快捷管理：唯一匹配服务时操作当前规则，未匹配服务时提供全局黑名单；加入和解除均需确认，保护现有 CIDR，范围变化时要求重新确认。
- 操作按钮显示当前规则及全局黑名单状态，相关记录同步更新；历史 HTTP 状态保持不变。复用 Nginx 发布与回滚机制，不自动封禁。

### 验证

- 增加独立 PR 验证工作流及 DDNS、ACME、通知、反代和日志浏览器回归测试。
- beta.4 完整 CI 与 FPK 发布通过。真实 DNS 服务商及 QQ 邮箱、Outlook 等客户端的环境差异仍欢迎反馈。

## 安装与升级

- 飞牛 fnOS：下载对应架构的 FPK，推荐普通权限版，确需特权操作时使用 Root 版。使用 SHA256SUMS.txt 校验安装包。
- Docker：支持 amd64 / arm64，镜像 `muxui/fonu:2.0.1` 或 `muxui/fonu:latest`。
- 升级前备份数据库、配置、证书及密钥，保留数据覆盖升级。迁移 030 将创建通知发送历史表，无需手工修改数据库。不要直接使用升级后的数据库降级。
- 黑名单是反代访问策略，不是系统防火墙。手动 Nginx 配置及默认兜底响应可能表现不同；请确认来源 IP 是可信真实客户端，避免误封 CDN 或路由器。

感谢 #43、#45 的反馈与 #44 的贡献，以及测试版用户的实际使用反馈。
